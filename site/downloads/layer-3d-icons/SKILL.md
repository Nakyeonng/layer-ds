# Layer 3D 아이콘

오브제 이름만 받아 시작한다. 사용처가 없으면 흰 모바일 앱 카드로 가정한다. 이름이 구체적이면 추가 질문 없이 이미지 생성을 시작한다.

## 기준 이미지

- [KPT 블록](references/kpt.png)은 승인 원본의 모서리, 부드러운 명암, 부품의 두께와 색 면을 보여준다.
- [말풍선](references/chat.png)은 승인 원본의 겹침과 둥근 볼륨을 보여준다.
- [나침반](references/compass.png)은 승인 원본의 구체적인 기능 부품과 기울기를 보여준다.
- [6종 배치](references/set-context.png)는 크기와 시각적 무게를 비교하는 자료다. 아래 줄의 달력·노트·돋보기는 확장 후보다.

가까운 승인 원본 1~2개를 골라 이미지 생성 도구에 실제 이미지 참조로 전달한다. 참조는 스타일과 디테일 수준의 기준으로 사용하고 새 오브제의 구조는 그 쓰임에 맞춘다.

## 후보 제작

1. 오브제의 쓰임을 드러내는 실루엣과 기능 부품 2~3개를 정한다. 얇고 단정한 부품, 부드러운 모서리, 소품마다 잘 읽히는 시점을 사용한다.
2. 같은 오브제의 후보 5개를 A안–E안으로 보여준다. 실루엣, 부품 비율, 자세를 의미 있는 범위에서 변주한다. 한 후보마다 팔레트나 재질을 바꾸어 차이를 만들지 않는다.
3. 본체는 Layer 3D v1 소프트 무광으로 렌더링한다. 주색 #6C9CFA, 보조색 #E9F0FF, 흰색과 #212329는 작은 기능 표식에 쓴다. 보라색과 남색을 추가하지 않는다. 넓은 좌상단 확산광, 완만한 명암과 옅은 접지 그림자를 사용한다. 렌즈처럼 투명함이 구조를 설명하는 부분에는 반사를 억제한 투명 표현을 쓸 수 있다.
4. 후보 비교판과 함께 흰 앱 카드에 기존 아이콘과 같은 크기로 놓은 적용 시안을 제공한다. 기존 아이콘은 참조 PNG를 그대로 배치한다. 작은 크기에서 읽히는지, 두께나 광택이 튀는지 확인해 적합한 후보를 추천한다. 생성 결과에서 부품이 빠지거나 문자가 틀렸으면 검수 결과에 적는다.
5. 추천과 함께 다음 안내로 답을 끝낸다: "'C안으로 정할게'처럼 후보를 골라 주시면 바로 기본 3/4 · 정면 · 띄운 컷 3장을 만들어 드릴게요. 고칠 점이 있으면 'C안으로 정할게. 받침을 조금 낮게'처럼 함께 적어 주세요."

## 선택 후 제작

후보 이름은 A안–E안이다. 스타일 이름(Layer 3D v1)과 헷갈리지 않는다. 사용자가 "C안으로 정할게", "C안", "C로 할게"처럼 후보 하나를 고르면 추가 질문 없이 바로 아래 3컷을 만든다. 고칠 점을 함께 적었으면 반영한다. 다른 각도는 만들지 않는다.

| 순서 | 코드 | 각도 | 쓰는 곳 |
| --- | --- | --- | --- |
| 1 | `34` | 위에서 약 20° 내려다보고 오른쪽으로 약 30° 돌린 3/4 뷰, 바닥에 놓인 상태 | 표지 메인, 대표 컷 |
| 2 | `front` | 정면에서 약 5° 위, 좌우 회전 없음, 바닥에 놓인 상태 | 본문 작은 아이콘, 여러 개 나란히 배치 |
| 3 | `float` | `34`에서 시계 방향으로 약 15° 기울이고 바닥에서 살짝 띄움, 그림자는 더 옅고 넓게 | CTA 장, 강조 장면 |

- 선택된 후보의 구조·부품 수·비율·색 배치·표기를 고정한다. 각 컷은 선택된 후보 이미지를 참조로 넣어 따로 생성한다.
- 3컷 모두 정사각 독립 투명 PNG, 오브제가 중앙에서 약 65%를 차지한다.
- 3컷을 선택된 후보와 나란히 놓고 검수한다. 부품이나 표기가 달라진 컷은 그 컷만 다시 만든다.
- 파일 이름은 `layer3d_<오브제-영문>_<각도코드>.png`로 한다(예: `layer3d_hourglass_34.png`).

## 전달

3컷을 위 표의 순서(기본 3/4 → 정면 → 띄운 컷)로 한 장씩 보여주고, 각 이미지 위에 각도 이름과 파일 이름을 한 줄로 적는다. 그다음 사용자에게 "이대로 등록할까요?"라고 한 번 묻는다. 사용자가 "등록", "좋아", "응"처럼 승인하면 아래 등록함 저장을 바로 한다. 고칠 점을 말하면 그 컷만 다시 만들고 다시 묻는다.

## 등록함 저장

승인된 3컷을 Google Drive의 `Layer 3D 등록함` 폴더 바로 아래에 저장한다.

- 폴더 링크: https://drive.google.com/drive/folders/17zoXokCPf-UUV519DgcpW7bT80wOUgMS
- 폴더 ID: `17zoXokCPf-UUV519DgcpW7bT80wOUgMS`

반드시 이 폴더 ID를 부모로 지정해 저장한다. 이름이 같은 다른 폴더를 찾거나 새로 만들지 않는다. 하위 폴더를 만들지 않고, `등록 완료`, `확인 필요` 폴더에는 넣지 않는다. 이 폴더에 접근할 수 없으면 아래 실패 안내를 따른다.

저장할 파일 4개:

| 파일 이름 | 내용 |
| --- | --- |
| `layer3d_<영문>_34.png` | 기본 3/4 컷, 투명 PNG |
| `layer3d_<영문>_front.png` | 정면 컷, 투명 PNG |
| `layer3d_<영문>_float.png` | 띄운 컷, 투명 PNG |
| `layer3d_<영문>_info.json` | 오브제 정보 (아래 형식) |

`info.json` 형식:

```json
{"name": "모래시계", "slug": "hourglass", "group": "시간", "note": ""}
```

- `slug`(영문)는 소문자 영어와 하이픈만 쓴다. 파일 이름의 `<영문>`과 같아야 한다.
- `group`은 기록·시간·정리·성장·대화·기타 중 하나다.
- `note`에는 사용자가 남긴 메모나 고친 점을 한 줄로 적고, 없으면 빈 문자열로 둔다.
- 이미 등록된 오브제를 고친 경우에도 같은 `slug`로 저장한다. 버전은 Claude가 등록할 때 정한다. 일부 각도만 고쳤다면 고친 각도의 PNG와 `info.json`만 저장한다.

저장을 마치면 "Layer 3D 등록함에 저장했어요. Claude가 다음 확인 때 세트에 등록합니다."라고 알린다.

Google Drive에 저장할 수 없으면(연결 안 됨, 권한 없음 등) 저장했다고 말하지 않는다. 그 이유를 한 줄로 알리고, 3컷과 `info.json` 내용을 그대로 보여주며 "이미지를 Layer 3D 등록함 폴더에 직접 올리거나 Layer 3D 아이콘 페이지에 붙여넣어 주세요"라고 안내한다.
