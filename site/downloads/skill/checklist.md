# Layer 화면 검수 체크리스트

화면을 다 만든 뒤 사용자에게 보여 주기 전에 위에서부터 하나씩 확인한다. 걸린 항목은 고친 뒤 다시 확인하고, 고칠 수 없는 것만 "남은 문제"로 알린다.

## 1. 틀
- [ ] 모바일은 375 너비, Template/Mobile(.layout-mobile) 안에 상태 바 → 앱 바 → 내용(좌우 20) 순서다.
- [ ] 흰 카드를 쌓는 목록 화면은 Background=Secondary(.layout-mobile--secondary)다.
- [ ] 하단 내비게이션은 메인 탭 화면(홈 · 실행목표 · 분석)에만 있다. 상세 · 작성 · 바텀시트 화면에는 없고, 대신 아래 Button Group이 있다.
- [ ] 웹은 Template/Web — 목록 화면 Type=List(펼친 LNB), 작업 화면 Type=Work(접은 LNB + 오른쪽 패널)다.
- [ ] 앱 바 제목 · LNB 현재 메뉴 · 하단 탭 현재 위치가 요청한 화면과 맞다.

## 2. 컴포넌트
- [ ] 모든 UI가 Layer 컴포넌트(Figma 인스턴스 · 웹 키트 클래스)다. 도형이나 새 CSS로 다시 그린 카드 · 버튼 · 탭 · 앱 바가 없다.
- [ ] components.json에 없는 컴포넌트 · 속성 · 변형 값을 쓰지 않았다.
- [ ] 컴포넌트 기본 글자("Label", "Title", "진행 중 1" 같은 예시 문구)가 남아 있지 않다.
- [ ] 회고 카드 배지는 한 자리: 작성 전 + 마감일이 있으면 D-day, 그 밖에는 상태(작성 중 · 제출 완료 · 분석 완료) 하나만.
- [ ] 개수는 Section Header 숫자로 쓰고 Badge로 만들지 않았다.

## 3. 버튼 · 겹침
- [ ] Primary 버튼은 화면당 하나다. 하단 CTA는 Button Group 안에 있다.
- [ ] Popup은 한 번에 하나이고, Popup 위에 Bottom Sheet가 없다.
- [ ] 딤드는 Popup · Modal · Bottom Sheet에만 있다. Menu · Popover · Dropdown은 딤드 없이 연 버튼 바로 아래 오른쪽 끝(사이 4)에 붙어 있다.
- [ ] 결과 알림은 Toast, 결정은 Popup, 고르거나 입력할 것이 많으면 Bottom Sheet다.

## 4. 색 · 글자 · 간격
- [ ] 색 · 간격 · 모서리는 토큰(Figma 변수 · var(--…))이고 새 색 코드 · px 값을 만들지 않았다.
- [ ] 파란색은 선택 · 강조 · 링크에만 썼다. 장식용 파란색이 없다.
- [ ] 회색 글자(text-tertiary)는 안내 · 보조 정보에만, 본문에는 쓰지 않았다.
- [ ] 글자는 Pretendard 텍스트 스타일(Figma 텍스트 스타일 · .text-* 클래스)이다.

## 5. 내용
- [ ] 요청에 적힌 문구 · 숫자 · 상태가 빠짐없이 들어갔다.
- [ ] 말투는 부드러운 해요체다("회고를 저장했어요", "작성을 그만둘까요?").
- [ ] 빈 화면은 Content 일러스트(200) + 해요체 안내 한 줄 + 행동 버튼 하나다.
- [ ] 이름 · 팀 이름은 가상 이름(김레이어, 이회고 …)이고 실제 사람 이름이 없다.

## 6. 웹페이지(HTML)일 때
- [ ] 채팅 미리보기라면 외부 주소(<script src> · <link> · 이미지 · 폰트 주소)를 하나도 부르지 않는다.
- [ ] <style>에 layer-inline.css의 @part base가 있고, HTML에 쓴 클래스마다 앞부분 이름의 @part가 빠짐없이 있다. (클래스 목록을 훑어 @part 이름과 하나씩 맞춰 본다)
- [ ] 붙여 넣은 CSS를 줄이거나 고쳐 쓰지 않았다.
- [ ] 아이콘 · 로고 · 일러스트는 SVG 코드가 들어 있다(빈 <span>이 없다).
- [ ] 마크업은 layer-examples.html 예시 구조 그대로이고 글자 · 숫자 · 상태 클래스만 바꿨다.

## 7. Figma일 때
- [ ] 문서 페이지가 아닌 새 페이지(또는 섹션)에 그렸다.
- [ ] 인스턴스를 떼어 내지(detach) 않았다.
- [ ] 다 그린 뒤 스크린샷으로 겹침 · 잘림 · 빈 자리가 없는지 눈으로 확인했다.

## 알려 주기(짧게)
- 쓴 틀과 주요 컴포넌트
- 검수에서 고친 것
- 지어낸 문구
- 부족했던 것(시스템에 없어서 가장 가까운 것으로 대신한 것)
