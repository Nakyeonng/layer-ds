시스템 영역

상태 바와 홈 표시줄은 iOS·Android가 그리는 영역입니다. 화면을 그릴 때 자리만 비워 두고, 우리 컴포넌트로 만들지 않습니다.

확정
2026-10-29

OS Bar 안의 시스템 부품(Time · Home Indicator 등)은 iOS·Android 키트에서 가져온 원격 인스턴스를 그대로 씁니다. 우리가 정하는 디자인이 아니고 개발에서 구현하지도 않으므로 로컬로 바꾸거나 토큰에 연결하지 않으며, 화면 점검의 원격 인스턴스 0개 기준에서 예외입니다. OS 모양이 바뀌면 키트만 바꿔 끼웁니다.

코드

<nav class="nav-bar" aria-label="주요 메뉴">
  <ul class="nav-bar__items">
    <li><a class="nav-item" href="/home" aria-current="page">
      <span class="nav-item__icon"><span class="icon icon-24">…</span></span>
      <span class="nav-item__label text-caption-11-medium">회고</span>
    </a></li>
    …
  </ul>
</nav>

선택된 탭은 aria-current="page"로 표시합니다. 화면 읽기 프로그램도 같은 정보를 읽습니다.
