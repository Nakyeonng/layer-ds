Color

Layer의 원색 팔레트입니다. 무채색 Gray를 기본으로, Blue를 브랜드 색으로, Green·Red·Orange를 상태 표시에 씁니다. 견본을 누르면 색상 값이 복사됩니다.

코드

css/color.css에 팔레트 전체(--color-이름-단계)와 아래 역할 토큰(--color-역할)이 들어 있습니다.
컴포넌트에서는 역할 토큰을 먼저 씁니다.

/* 역할 토큰 (권장) */
color: var(--color-text-primary);
background: var(--color-bg-secondary);
border-color: var(--color-border-default);

/* 역할이 없는 곳은 팔레트 단계 */
color: var(--color-gray-600);

역할 토큰

컴포넌트를 만들 때는 팔레트 단계보다 이 역할 토큰을 먼저 고릅니다. 실제로 쓰이는 곳이 있는 것만 19개로 정리했습니다.
Hover·Pressed는 State 규칙(팔레트 한 칸·두 칸)을 따르므로 역할 토큰을 따로 두지 않습니다.

Figma 변수

Figma의 Color 변수 모음에 팔레트 55개가 코드와 같은 이름으로 들어 있고, Color Role 모음에 역할 토큰 19개가 팔레트를 가리키는 별칭으로 들어 있습니다.
팔레트 변수는 고르기 목록에서 숨기고 역할 토큰만 보이게 했습니다.

Figma 변수코드 토큰예
color/gray/0 ~ color/gray/900--color-gray-0 ~ 900Gray 0 = #FFFFFF, 예전 스타일 이름은 Gray/000
color/blue/50 ~ 900 · purple · green · red · orange--color-blue-600 등단계 번호가 그대로 이름
color/opacity/4 ~ 100--color-opacity-72 등#06080C에 투명도가 값 안에 들어 있음(칠 불투명도는 100%)

모든 변수에 코드 이름(var(--color-text-primary) 등)과 쓰는 곳 설명이 들어 있어 Dev Mode와 Figma MCP에서 그대로 읽힙니다.
글자 토큰은 글자 색에서, 바탕 토큰은 채우기에서, 테두리 토큰은 선 색에서만 고를 수 있습니다.

결정 기록

추가
2026-10-27

역할 토큰 19개를 만들고 컴포넌트의 기본 상태 색 414곳을 팔레트에서 역할 토큰으로 옮겼습니다. Hover·Pressed 상태는 팔레트 단계를 그대로 씁니다.

반영
2026-10-27

Figma에 Color 변수 55개를 만들고, 컴포넌트와 문서 대지에서 Color 스타일로 연결된 색 1,851곳을 같은 이름의 변수로 옮겼습니다. 값은 원래 스타일과 모두 같은 것을 확인했습니다. 스타일 없이 숫자로만 들어 있던 팔레트 색 28곳(진행 바, 토스트, 스크롤 바 등)도 변수에 연결했습니다.

확인 필요
2026-10-27

변수로 옮기지 않은 것: 서비스 대표 화면과 AI 시안(문서가 아닌 화면), 외부 라이브러리 컴포넌트(상태 바, 홈 표시줄, 키보드, Fields 대지에 남은 외부 Text Input), Lists 대지의 숨은 레이어 2개(brand Navy 스타일, #191926), 아이콘 안의 검정. Profile 배경 #D0D3DB는 2026-10-28에 Gray 400으로 맞췄습니다.

반영
2026-10-26

Orange 300 라벨이 "Orange / 00"으로 잘못 적혀 있던 것을 Figma와 코드 모두 "Orange / 300"으로 고쳤습니다.
