Tabs

탭은 같은 화면 안의 내용을 몇 갈래로 나눠 보여 주는 요소입니다.
밑줄로 선택을 표시하는 Text 탭은 화면의 주요 구분에, 칸 모양의 Box 탭은 목록을 거르는 보조 구분에 씁니다. 탭이 많아 화면을 넘치면 Scrollable로 옆으로 밀어서 봅니다.

확정Figma 파일2026-11-04 기준

예시

탭을 눌러 보세요. Box 탭은 옆으로 밀면 가려진 탭이 나오고, 더 볼 탭이 있는 쪽 가장자리만 흐려집니다.

Text 탭

왼쪽 정렬은 탭 이름 길이만큼 차지하고 2~4개까지 씁니다. 같은 너비는 칸을 똑같이 나누고 2~3개까지 씁니다.
아래 구분선은 필요할 때만 넣습니다(Outlined).

크기 Size 18 · 14

Text 탭은 모바일과 웹이 같은 컴포넌트입니다. 화면의 주요 구분에는 Size 18(탭 간격 8)을, 웹 패널 · 왼쪽 메뉴(LNB) 안에는 Size 14(탭 간격 4)를 씁니다.
높이는 40이고 여백이 없습니다. 모바일 화면에서는 감싸는 프레임이 위 12 · 좌우 20 여백을 줍니다.

Size 14: 실행목표 패널(진행 중 · 지난), LNB(전체 · 개인 · 팀).
Size 18 + 구분선: 웹 회고 상세 패널 위(질문 · 개별 · 분석).
Figma Tabs/Text Tabs · Size=18 · 14, 칸 수는 Show Tab 3 · 4, 구분선은 Show Divider, 이름과 선택은 각 탭(Text Tab Item)에서 바꿉니다.

Segmented Control

같은 내용을 보는 기준을 바꾸는 2~3칸 전환입니다. 예: 분석 결과의 개인 · 팀.
내용 영역 자체를 나누면 Text 탭을, 목록을 거르면 Box 탭을 씁니다.

칸위아래 6 · 좌우 12, 모서리 6, Body 12 SemiBold Gray 700 · Hover Gray 200 바탕

밑줄 없는 Text 탭

선택을 글자색만으로 표시하는 2개짜리 탭입니다. 높이는 글자만큼이고, Date Time Picker의 오전/오후처럼 작은 영역 안에서 씁니다.

Box 탭

탭이 많으면 Scrollable, 2~3개면 같은 너비로 씁니다.

코드

<link rel="stylesheet" href="css/tabs.css">

<!-- Text 탭 (같은 너비 + 구분선) -->
<div role="tablist" class="tabs tabs--fixed tabs--outlined">
  <button role="tab" class="tab" aria-selected="true">진행 중</button>
  <button role="tab" class="tab" aria-selected="false">완료</button>
</div>

<!-- Box 탭 (Scrollable) -->
<div role="tablist" class="box-tabs box-tabs--scroll">
  <button role="tab" class="box-tab" aria-selected="true">전체</button>
  <button role="tab" class="box-tab" aria-selected="false">이번 주</button>
  …
</div>

<script>
  // 더 볼 탭이 있는 쪽 가장자리만 흐리게
  document.querySelectorAll('.box-tabs--scroll').forEach(function (el) {
    function fog() {
      var max = el.scrollWidth - el.clientWidth;
      el.style.setProperty('--fog-l', el.scrollLeft > 1 ? '40px' : '0px');
      el.style.setProperty('--fog-r', el.scrollLeft < max - 1 ? '40px' : '0px');
    }
    el.addEventListener('scroll', fog, { passive: true }); fog();
  });
</script>

결정 기록

확정
2026-10-27

왼쪽 정렬 탭(Subtitle 18 SemiBold)과 같은 너비 탭(Title 18 Bold)의 글자 스타일 차이는 의도한 것입니다.

반영
2026-10-27

같은 너비 탭은 선택되면 글자가 2px 올라갔는데, 선택 여부와 상관없이 같은 높이(위 7px)로 맞췄습니다. Figma 이름도 Sheet에서 Fixed로 바꿨습니다.

반영
2026-10-27

같은 너비 탭의 글자를 행간 140%의 Title 18 Bold 스타일에 연결했습니다(외부 라이브러리 스타일은 150%). Popup 제목과 같은 스타일입니다.

추가
2026-10-27

밑줄 없는 버전(Underline = Off)을 추가했습니다. Date Time Picker의 오전/오후가 이 버전을 씁니다.

추가
2026-10-27

호버 상태를 추가했습니다. Text 탭은 글자 Gray 600, Box 탭은 배경 Gray 200입니다.

반영
2026-10-27

Box 탭 선택 색은 Gray 800으로 정했습니다. 선택 안 된 글자는 "Text/Disabled" 변수 대신 원본 Color 스타일 Gray 500에 연결했습니다.

반영
2026-10-27

Scrollable은 375px 안에서 잘리고, 더 볼 탭이 있는 쪽 가장자리를 흐리게 처리했습니다. 숨어 있던 "Component 10" 레이어는 지웠습니다.
